# Fallow

[![build](https://github.com/salvagedisc/fallow/actions/workflows/build.yml/badge.svg)](https://github.com/salvagedisc/fallow/actions/workflows/build.yml)

A **Minecraft 1.21.1 / NeoForge** modpack for a permanent world shared with friends: exploration through the mist, settlements, Create and aviation, long-term farming and animal husbandry. No minimap, no teleportation, no vanilla monsters: the difficulty comes from the environment.

| | |
|---|---|
| Minecraft | 1.21.1 |
| Loader | NeoForge 21.1.251 |
| Tooling | [packwiz](https://packwiz.infra.link/) → `.mrpack` export (Modrinth) |
| Version | `0.x` (prototype, disposable worlds); `1.0.0` = launch of the permanent world |
| Content | see the [mod registry](docs/mods.md) |

## Play

1. Install the [Modrinth App](https://modrinth.com/app).
2. Accept the *Share* invitation you received, **or** download the `.mrpack` from the latest [release](../../releases) (or the artifact of the latest [build](../../actions/workflows/build.yml)) and use *+ → Import from file*.

## The repository

```
fallow/
├── pack/                  ← packwiz root: the only content of the .mrpack
│   ├── pack.toml          ← name, version, Minecraft and NeoForge pinned
│   ├── index.toml         ← generated by `packwiz refresh`, do not edit
│   ├── mods/              ← one .pw.toml per mod (Modrinth source)
│   ├── config/            ← mod configs (shared)
│   ├── defaultconfigs/    ← configs applied to every new world
│   └── kubejs/            ← rules layer: startup/server/client scripts
│       └── data/fallow/   ← datapack data loaded by KubeJS
├── scripts/               ← dependency-free Node.js tooling (+ tests)
├── docs/
│   ├── vision.md          ← philosophy of the pack
│   ├── mods.md            ← registry: kept, to test, rejected
│   ├── feuille-de-route.md ← sub-projects and open work items
│   ├── plan/              ← full modpack plan (mods, configs, scripts)
│   ├── decisions/         ← one record per settled decision
│   └── conception/        ← specs and implementation plans
├── .github/workflows/     ← build (every push) and release (tag vX.Y.Z)
├── CONTRIBUTING.md        ← working conventions
└── CHANGELOG.md
```

## Development

Requirements: Node.js ≥ 20 and [packwiz](https://packwiz.infra.link/installation/).

| Command | Purpose |
|---|---|
| `npm test` | Tooling tests |
| `npm run check-deps` | Checks that the dependencies declared in the jars are provided by the pack (also run in CI) |
| `npm run check-fr` | Checks that every text of every mod has a French translation (also run in CI) |
| `npm run sync -- --instance "Fallow test"` | Brings the mods (and, with `--configs`, the configs) tested in the Modrinth App instance back into the repository |
| `cd pack && packwiz refresh` | Regenerates `index.toml` after any change to `pack/` |
| `cd pack && packwiz mr export` | Produces the `.mrpack` locally |

The full workflow (adding a mod, test branches, versions, release) is described in [CONTRIBUTING.md](CONTRIBUTING.md). The documentation is indexed in [docs/](docs/README.md).
