# Plan du modpack

Ce dossier accueille le **plan complet du modpack** : sélection argumentée des mods par système, réglages à appliquer (fonctions de mods à désactiver, configs), scripts KubeJS et données datapack à écrire, ordre de mise en place.

Le plan s'appuie sur la [vision](../vision.md), le [registre des mods](../mods.md) et les [décisions](../decisions/README.md) déjà prises. Une fois validé, chaque choix est appliqué au pack selon [CONTRIBUTING.md](../../CONTRIBUTING.md) : un mod par commit, configs dans `pack/config/` ou `pack/defaultconfigs/`, scripts dans `pack/kubejs/`, et une fiche dans `docs/decisions/` pour chaque arbitrage.
