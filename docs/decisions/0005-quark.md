# 0005 — Quark: the essentials only

- **Date**: 2026-09-24
- **Status**: config `pack/config/quark-common.toml` (to be checked on first launch)

## Rule
Keep the essentials of Quark (inventory sorting and comfort) and nothing that distorts the pack. Every "to be discussed" module is disabled. Quark's rope is disabled in favour of Supplementaries' (pulleys).

## Enabled
- **Management**: Inventory Sorting, Easy Transferring, Expanded Item Interactions, Quick Armor Swapping, Hotbar Changer, Item Sharing.
- **Interface**: Chest Searching, Improved Tooltips, Usage Ticker, Microcrafting Helper, Back Button Keybind, Buckets Show Inhabitants, Variant Animal Textures, Camera.
- **Building**: Vertical Slabs/Planks, Hedges, Hollow Logs, Leaf Carpet, Thatch, Wooden Posts, Shingles, Framed Glass, Grate, Industrial Palette, Compressed Blocks, More Stone Variants, More Brick Types, More Mud Blocks, Raw Metal Bricks, Sturdy Stone, More Potted Plants, Variant Chests/Bookshelves/Ladders/Furnaces, Glass Item Frame, Shear Vines, Nether Brick Fence Gate.
- **Tools**: Seed Pouch, Trowel, Parrot Eggs.
- **Tweaks**: Reacharound Placing, Lock Rotation, Slabs To Blocks, Double Door Opening, Enhanced Ladders, Horses Swim, Simple Harvest, Hoe Harvesting, Pig Litters, Pat The Dogs, Grab Chickens, Safer Creatures, Petals On Water, Map Washing, Automatic Recipe Unlock, Emotes, Armed Armor Stands, Dyeable Item Frames, More Banner Layers, No Durability On Cosmetics, Metal Buttons, Obsidian Plate, **Villagers Follow Emeralds** (escorting survivors), No More Lava Pockets.

## Disabled (notably)
Entire categories: creatures, experimental, oddities. World generation (except No More Lava Pockets). Pathfinder Maps (location), everything touching the End/Elytra, Feeding Trough (self-sufficient animal husbandry), More Villagers and Zombie Villagers (survivors), Diamond Repair and Gold Tools Have Fortune (Overgeared balance), Greener Grass (Ecliptic's seasonal colours), Automatic Tool Restock, Auto Walk, Shiba, Stonelings, Toretoise, Fairy Rings, Fallen Logs.

## Good to know
- IDAS (later) uses Quark blocks: some building or stone modules may need to be re-enabled.
- The key names are inferred from the Quark 4.1 classes; compare with the config generated on first launch and fix it if a module was not picked up.
